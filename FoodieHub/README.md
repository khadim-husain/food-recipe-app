# FoodieHub – Recipe Browsing and Management App

A React Native + Expo starter app for a recipe browser and personal recipe manager.

## Features
- 10 recipe categories and starter recipes
- Search and recipe detail view
- Ingredients, instructions, prep time, servings, calories and difficulty
- Favorites
- My Food / My Recipes section
- Add, edit and delete personal recipes
- Back navigation

## Run locally
1. Install Node.js.
2. Extract this ZIP.
3. Run `npm install`.
4. Run `npx expo start`.
5. Open with Expo Go or use the web preview.

## Use with Expo Snack
Create a new Snack at https://snack.expo.dev and paste the contents of `App.js` into the editor. Add the dependencies shown in `package.json` if Snack does not add them automatically.

## GitHub submission
Create a **public** repository on GitHub, upload `App.js`, `package.json`, and `README.md`, then submit that repository's real URL on Coursera.

## Notes
- Recipes are stored in app memory for this starter version; they reset when the app reloads.
- The image field accepts an image URL. This starter does not implement device gallery upload or cloud/database persistence.
- Review and test the app yourself, and follow your course's rules about AI assistance before submitting.
